# MindBridge - Resume Summary

## Project Highlights (3 Bullet Points)

- **Full-Stack Mental Health Platform**: Developed a comprehensive mental health support web application using Next.js 15, TypeScript, and PostgreSQL with Prisma ORM, featuring secure JWT authentication, role-based access control, and a responsive UI built with Tailwind CSS.

- **AI-Powered Mental Health Support**: Integrated AI chatbot functionality for 24/7 mental health counseling, implemented standardized psychological assessments (PHQ-9, GAD-7, PSS-10), and built an appointment booking system for professional counselor consultations.

- **Community & Resource Management**: Created a peer support community platform with moderated discussions, a multilingual resource hub with psychoeducational content, and an admin dashboard for user management and analytics tracking.
